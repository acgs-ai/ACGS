# Quickstart — Enhanced Agent Bus Analysis

**Branch**: `001-enhanced-agent-bus-analysis` | **Date**: 2026-05-14

Goal: bring the observer up against a local bus, publish a few events (including one targeted at an unregistered handler), open the console at `/console/bus`, and confirm you can see the trace, the wiring-defect finding, and the constitutional-hash anchor.

---

## Prerequisites

- Repo at `govern-zone/` root, branch `001-enhanced-agent-bus-analysis` checked out.
- `make install` has run at least once (`pnpm install` + `uv sync`).
- `acgi-ai` dev server is buildable (`pnpm -F acgi-ai build` succeeds).

> The package `packages/agent-bus-analyzer/` does **not** exist yet at the time of this writing — it is the deliverable of the Phase 2 tasks generated by `/speckit-tasks`. This quickstart is the operator-facing acceptance procedure; it will become runnable once those tasks complete.

---

## 1. Bring up a local `EnhancedAgentBus`

Use the package's existing local backend so we do not need Kafka or Redis in development:

```bash
cd ACGS
python -m start_agent_bus --backend=local
```

Expected: the bus prints its constitutional hash on boot — confirm it matches `608508a9bd224290` (or your environment's override). This is the value the analyzer will anchor every captured event to.

---

## 2. Attach the analyzer (read-only)

In a second terminal:

```bash
cd packages/agent-bus-analyzer
python -m agent_bus_analyzer observer \
    --bus-endpoint=local:default \
    --audit-file=/var/log/gove-zone/audit.jsonl \
    --store-dir=./var/traces
```

Expected output (one line per second):
```
[observer] bus attached (read-only) | audit attached (RO) | constitutional_hash=608508a9bd224290
[observer] queue=0/10000 | writer_backlog=0 | ingest_gap=closed
```

If the audit file is missing, the observer fails closed (exits 1 with `IntegrityStoreUnavailable`). This is the FR-008 contract — the analyzer never silently records hash-less events.

---

## 3. Generate traffic

In a third terminal, send a small handful of bus messages:

```bash
python -m agent_bus_analyzer dev-traffic \
    --target=local:default \
    --count=10 \
    --include-unwired-handler
```

`--include-unwired-handler` deliberately publishes one event targeting a non-existent handler — this is the canonical Story 2 acceptance case.

---

## 4. Open the console

```bash
pnpm -F acgi-ai dev
```

Navigate to `http://localhost:5173/console/bus`. Verify:

- **Trace list**: at least one trace shows up with `event_count >= 10`. Worst-event-status badge shows `unwired-handler` (red).
- **Inspector** (click the trace): 11 events visible (10 dispatches + the unwired one). Integrity status: `intact`. Constitutional hash displayed at the trace header.
- **Wiring defects panel**: one finding with `kind=unwired_dispatch` and `handler_name=<the bogus name>`. `detected_at` is within 60 seconds of when you published — this is the SC-003 acceptance.

---

## 5. Prove tamper-evidence

In a fourth terminal, simulate a malicious edit:

```bash
TRACE_FILE=$(ls -t packages/agent-bus-analyzer/var/traces/*.jsonl | head -1)
# Flip a single byte in the middle of the file
python -c "import sys; p=sys.argv[1]; b=open(p,'rb').read(); i=len(b)//2; open(p,'wb').write(b[:i]+(b'X' if b[i:i+1]!=b'X' else b'Y')+b[i+1:])" "$TRACE_FILE"
```

Re-open the same trace in the console. Verify:

- **Integrity status**: now `tampered` (not `intact`, not `unknown`).
- A specific `event_id` is named as the first chain-break point.
- The trace's "clean" badge is suppressed — even if there are no policy violations, the view refuses to call a tampered trace clean. This is the SC-004 / Story 3 acceptance.

Restore from a clean copy or re-run §3 to start fresh.

---

## 6. Run the test suite

```bash
cd packages/agent-bus-analyzer
pytest -q
```

The two load-bearing tests:

- `test_bus_dispatch_capture.py` — boots a local bus, publishes through it, asserts the event landed in the store via the **subscription path** (not by calling the analyzer's classifier directly). This is the dispatcher-level test the constitution requires.
- `test_chain_integrity.py` — captures a trace, flips a byte, asserts the verifier exits non-zero.

Frontend:

```bash
pnpm -F acgi-ai test BusAnalysis
```

## Troubleshooting

**`IntegrityStoreUnavailable` on observer start**
The audit JSONL is missing or unreadable. The observer is fail-closed by design (FR-008). Create `/var/log/gove-zone/audit.jsonl` or point `--audit-file` at the local equivalent.

**Trace shows `integrity_status=unknown` even on a clean run**
The trace's first event has a non-null `prev_hash`. Indicates the JSONL was truncated mid-stream or rotated; rerun §3 to produce a fresh complete trace.

**Wiring defect doesn't show up**
The bus's handler registry may not have been sampled yet (default 30s). Wait for one full sample interval or pass `--registry-poll-seconds=5` to the observer for development.

**Console page renders but trace list is empty**
Check `packages/agent-bus-analyzer/var/traces/` exists and is readable by the dev server's user. The SQLite index lives next to the JSONL files (`index.sqlite`); deleting it is safe — it is recomputed from the JSONL on next observer start.
