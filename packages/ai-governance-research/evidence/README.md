# Evidence

The hub treats evidence as a first-class governance object. Every strong claim should point to a source, test, log, receipt, or review record.

## Evidence quality levels

| Level | Example | Use |
| --- | --- | --- |
| A | Current official standard, law, upstream documentation, command output, replayable log | Strong operational or source-backed claim |
| B | Peer-reviewed or reputable research, model/system/data card, independent eval | Decision support with caveats |
| C | Internal design notes, plans, vendor marketing, unverified summary | Planning only; do not use as proof |
| D | Agent assertion without source | Not evidence |

Use `source-register.md` as the starting source map.
