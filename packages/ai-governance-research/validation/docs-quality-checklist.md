# Docs Quality Checklist

## Structure

- [ ] README explains mission and routing.
- [ ] Agent decision protocol includes allow / deny / escalate / ask.
- [ ] Problem-solution map routes common governance problems to controls.
- [ ] Solution catalog pages include required headings.
- [ ] Playbooks are actionable and copy/paste-friendly.
- [ ] Templates are reusable.
- [ ] Source register includes official/upstream sources.

## Claim safety

- [ ] No unsupported certification, compliance, or deployment-readiness claims.
- [ ] Legal/regulatory statements point to sources and caveats.
- [ ] Date context is visible for time-sensitive sources.
- [ ] The hub says it is not legal advice or certification.

## Agent usefulness

- [ ] Agents know what to ask first.
- [ ] Agents know when to stop or escalate.
- [ ] Agents know what evidence is required.
- [ ] Agents know how to record a decision.
- [ ] Agents know when to come back after context changes.
