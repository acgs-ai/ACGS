# Playbooks

Playbooks are step-by-step procedures agents can follow.

| Playbook | Use when |
| --- | --- |
| `choose-a-governance-pattern.md` | An agent needs to pick controls |
| `govern-an-agent-tool-call.md` | A tool/action needs runtime approval |
| `produce-an-audit-trail.md` | Evidence and records are required |
| `escalate-to-human-review.md` | The task exceeds agent authority |
