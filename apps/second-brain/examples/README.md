# Demonstration sources

`demo-sources.json` is a small deterministic dataset for Second Brain capture
demonstrations. Each array item is a valid body for
`POST /api/v1/captures/text`; project IDs, tag IDs, and idempotency keys are
intentionally omitted so an operator can add values for the active workspace.
The same title and content can be pasted through Inbox.

The records are synthetic project examples written for this repository. They
contain no personal data, private material, quotations, or third-party licensed
content.
