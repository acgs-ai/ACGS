# docs/internal — Retained Engineering History

This directory holds engineering and process material kept for maintainers:
audits, evaluations, and dated plans that are not part of the reviewer-facing
product documentation set.

**This repository is public. `internal/` is an organizational label, not an access
control.** Anything placed here is published. Material that must not be published —
pricing, investor and fundraising documents, competitive positioning, sales
collateral — does not belong anywhere in this repository; it lives in the
maintainers' private store.

Public product docs live in `docs/` (root), `README.md`, and package-local docs.
Nothing in `docs/internal/` is a product claim or a support commitment.

## Contents

- `architecture-audit.md` — ownership inventory and audit method
- `hub-verification-report.md` — dated QA verification report
- `HERMES_DOJO_ONBOARDING_EVALUATION.md` — integration evaluation
- `productization/` — enterprise architecture, deployment options, onboarding,
  API documentation, security-whitepaper outline
- `superpowers/` — dated implementation plans and design specs
