# Support

Thanks for using ACGS. Here is where to get help.

## Start here

- **New to the project?** Read [`docs/START_HERE.md`](docs/START_HERE.md) and the
  canonical [`docs/PROOF_PATH.md`](docs/PROOF_PATH.md).
- **Prove the core invariant locally:** run `make review` (bare-clone-safe — no
  submodules or tokens required). See the README "Verify the invariant locally".
- **Claims / scope:** [`docs/CLAIMS.md`](docs/CLAIMS.md) and
  [`docs/SECURITY_MODEL.md`](docs/SECURITY_MODEL.md) document exactly what is and
  is not claimed.

## Questions and bugs

- **Bug reports / feature requests:** open a GitHub issue using the templates.
- **Security vulnerabilities:** do **not** open a public issue — follow
  [`SECURITY.md`](SECURITY.md).
- **Contributing:** see [`CONTRIBUTING.md`](CONTRIBUTING.md).

## Scope of support

This is an early-stage (`0.1.0` platform; `gove-zone` kernel `1.0.0rc1` Beta)
research artifact. Support is best-effort by maintainers and the community; there
is no commercial support SLA. Nested submodule packages (`acgs-lite`,
`Acgs-Swarm`, `clinicalguard`, `ACGS-agency-agents`) have their own repositories
and support state.
